# Game Bar crosshair

The crosshair controls are in **System → FPS → Crosshair ON/OFF**. Use the adjacent gear to change color and size or center the widget.

First open **Win + G → Widgets → Xenon Crosshair**, pin it, and enable click-through. Put Game Bar on the game display before using Center. A newly launched widget starts OFF.

See the [widget guide](../apps/game-bar-crosshair/README.md) for installation, local build requirements, behavior, and verification limits.
